# Crona v1.10.0-beta.10

Crona v1.10.0-beta.10 makes first-run workflows clearer, improves Today and Momentum, and makes focus recovery and check-in editing more reliable. The local IPC protocol stays at `1.7`.

## First-run workflows

- Onboarding and form dialogs have clearer keyboard guidance, tighter layouts, and actionable errors. Failed saves keep entered values available for correction.
- Issue and focus terminology is consistent across the first-run flow, and report exports take fewer steps for common destinations.
- The CLI shows actionable kernel errors without exposing low-level transport codes.

## Today and Momentum

- Today’s empty state gives a clear next action. The daily layout uses space more effectively, and Momentum goals and contributor details are easier to read.
- Starting focus from an issue in Backlog now offers an explicit status recovery step. If recovery finishes after the dialog closes, it preserves the form currently on screen.
- Extending an expired Pomodoro can start the next focus segment directly.

## Reliability fixes

- Saving a check-in immediately updates Today, so pressing `w` reopens the saved values in Edit mode. Date changes, delayed reads, and deletion keep the displayed record in sync.
- Errors during focus recovery remain visible, and the issue status is refreshed without replacing unrelated input.
